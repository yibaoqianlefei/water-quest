# 甜蜜蜜复习 · L&M

面向建筑学课程复习的静态网站，包含 176 道题、8 个章节关卡和综合终章。

## 功能

- L&M 甜蜜卡通主题与 UI 动画。
- 轻柔的点击、选项、答题、通关、兑换和复盘音效；默认静音，可调音量，设置保存在本机。
- 考试倒计时（默认北京时间 2026 年 11 月 11 日 12:20，可调整）与考前冲刺安排。
- 每日 12 题目标、三连对和错题修复奖励；心心兑换夸夸卡、休息卡及考后心愿卡。
- 答错扣 1 心心（最低 0），填写至少 6 字易错提醒后继续；奖励和提醒随进度备份保存。

- 单选、多选、判断、关键词填空、数字计算，以及 32 道名词解释。
- 名词解释先独立作答，再按 3 个复习要点自评；支持草稿保存。
- 错题本、收藏、学习记录、浏览器本地进度及 JSON 备份导入导出。
- 独立的课后题复习：26 道教师复习提纲题＋11 道课堂原题，支持筛选、草稿、要点对照、自评标记及备份。入口 `#homework`，课堂原图入口 `#classroom`，单题可用 `#homework/class54` 直接打开。
- 37 道题均附对应的原图区域（16 张图片），保留原有批注，可展开及放大；第 54 题为水泵看图题。图片裁取页码记录在 `docs/classroom/sources.json`。
- 两份复习资料：10 页考前精简版、34 页完整复习手册，支持在线翻页和 Word/PDF 下载。

## GitHub Pages

本项目的发布目录是 `docs/`。在仓库 **Settings → Pages** 中，将发布来源设为 **Deploy from a branch**，选择 **main** 分支和 **/docs** 文件夹后保存。

网站使用相对路径，可直接部署在 GitHub Pages 项目子路径下，无需构建或安装依赖。`docs/.nojekyll` 用于按静态文件发布。

## 检查与维护

运行 `npm test` 检查题库、评分、抽题、进度恢复、名词解释自评、考前奖惩、音效开关及课后题保存逻辑。网页源码位于 `docs/`，题库在 `docs/bank.js`，评分逻辑在 `docs/engine.js`。

学习进度保存在当前浏览器及当前网站地址下。切换设备或网站地址前，可在原站“学习记录”导出进度，再在新站导入。

## 内容说明

课后题文本核对自《水💦28分.pdf》第 2—11 页，并标明每题来源。答案要点来自课程讲义与已有复习手册；原图批注保留但不冒充教师标准答案。考试通知为 2026 年 11 月 11 日 12:20—13:50；已有用户设置不会自动覆盖，可在课后题页同步。

2026-11-08 核对：补收第 54 题（B），复算 17 道数值计算例题；176 道闯关题答案键未发现需翻转项。完善临时高压定义及热水循环表述，区分人均用水定额和总用水量。第 51 题 C 项有歧义，第 60 题缺少规范版本，保留原图参考 D 并要求自评掌握；第 61 题补充地下商店、面积及版本条件。网站目录可展开“答案核对记录”查看范围和外部核对链接。

本项目根据课程复习资料整理，模拟题不代表真实考卷；名词解释要点为练习自评标准，不是老师的正式评分细则。课程旧题中的数值与定义按题干限定理解。

仓库包含网站运行文件、两份生成的复习资料，以及用户指定课堂题的原图区域，不包含整份学校原始课件 PDF。
